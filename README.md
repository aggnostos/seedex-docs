# Seedex documentation

The source of [docs.seedex.net](https://docs.seedex.net), published with GitBook.

- `en/` and `ru/` hold one space per language: `README.md` is the landing page, `SUMMARY.md` the table of contents.
- `gitbook-docs.yaml` maps the two directories onto the site.

The code lives in [seedex-openwrt](https://github.com/aggnostos/seedex-openwrt) and [seedex-agent](https://github.com/aggnostos/seedex-agent).
