# Contributing

Bug reports, suggestions, and pull requests are welcome in [seedex-openwrt](https://github.com/aggnostos/seedex-openwrt), [seedex-agent](https://github.com/aggnostos/seedex-agent), and [seedex-docs](https://github.com/aggnostos/seedex-docs).

The guidelines live with the code: [seedex-openwrt/CONTRIBUTING.md](https://github.com/aggnostos/seedex-openwrt/blob/main/CONTRIBUTING.md) for the router and [seedex-agent/CONTRIBUTING.md](https://github.com/aggnostos/seedex-agent/blob/main/CONTRIBUTING.md) for the server. Each covers what to include in a bug report, the code style, `make lint`, how to test a change, and the commit format. Requirements, project structure, and the build are on the [seedex-box](seedex-box.md) and [seedex-agent](seedex-agent.md) pages.

Fixes to the text of this site go to seedex-docs. The English and Russian pages mirror each other: a change in meaning, rather than wording, goes into both.
