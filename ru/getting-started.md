# Начало работы

Эта страница проводит от обычного роутера до роутера, который отправляет трафик через серверы, которыми владеете вы. Seedex работает с любым сервером WireGuard (WG), AmneziaWG (AWG) или sing-box: используйте клиентские конфиги, которые у вас уже есть, или разверните сервер с seedex-agent, и роутер будет забирать конфиги оттуда сам.

## Перед началом

Вам понадобится:

* Роутер на OpenWrt 24.10.2 или новее с выходом в интернет.
* Сервер: любой сервер WG, AWG или sing-box с его клиентскими конфигами, либо сервер на Ubuntu 24.04 или новее с публичным IP-адресом и правами root для seedex-agent.

## Установите seedex-box

На роутере запустите установщик от root:

```sh
wget -O - https://aggnostos.github.io/seedex-openwrt/install.sh | sh
```

Установщик подключает фид пакетов Seedex и ставит `seedex-box` и `luci-app-seedex` для LuCI. Ничего не запускается, пока вы не примените первый конфиг. Чтобы обойтись без LuCI, запустите установщик с `| sh -s -- --no-luci`.

## Используйте свои серверы

Если сервер у вас уже есть, роутер принимает то, чем пользуются его клиенты: файл `.conf` WG или AWG, файл `.json` sing-box или ссылку вида `vless://...`.

1. Скопируйте файлы конфигов на роутер или держите ссылки под рукой.

2. Импортируйте их:

   ```sh
   sdx import awg.conf
   sdx import wg.conf
   sdx import sing-box.json
   sdx import 'vless://...'
   ```

   Имя файла становится именем конфига, ссылка приносит своё имя. Каталог импортирует все конфиги в нём, а текстовый файл, в котором по одной ссылке на строку, — все ссылки из него.

3. Примените изменения:

   ```sh
   sdx apply
   ```

   Команда сохраняет конфиги и запускает сервисы: поднимаются туннели, вместе с ними стартуют Router и DNS.

Переходите к разделу [Проверьте статус](#проверьте-статус). Несколько конфигов — нормально: роутер ведёт трафик через самый быстрый живой туннель и переключает его, когда туннель падает.

## Установите seedex-agent

Если сервер есть, но на нём ещё ничего нет, seedex-agent его настроит.

1. На сервере запустите установщик от root:

   ```sh
   wget -O - https://github.com/aggnostos/seedex-agent/releases/latest/download/install.sh | bash
   ```

   Установщик скачивает последний релиз и ставит команду `sdx`, AWG, WG, sing-box и бинарник Link API. Он генерирует ключи сервера, открывает порты и включает сервисы. Пока ничего не запущено. Чтобы обновиться позже, запустите ту же команду ещё раз.

2. Добавьте VPN-клиентов для роутера и прокси-протокол. Например, клиента AWG, клиента WG и VLESS Reality на порту 443. В сети, где фильтруют WG, например в России, работает только клиент AWG; роутер сам выбирает самый быстрый живой туннель:

   ```sh
   sdx vpn add awg router
   sdx vpn add wg router
   sdx proxy add vless 443
   ```

3. Запустите сервисы:

   ```sh
   sdx start
   ```

   Сервисы не работают, пока вы их не запустите. `sdx start` поднимает каждый протокол, у которого есть клиент или порт, поэтому выполните его после первого `add`; протокол, добавленный позже, запускается через `sdx vpn start` или `sdx proxy start`.

4. Соедините роутер:

   ```sh
   sdx link add router
   ```

   Команда печатает токен, отпечаток сертификата и одну строку для роутера. Сохраните вывод. Токен показывается один раз.

## Подключите роутер к seedex-agent

1. На роутере вставьте строку, которую напечатал сервер:

   ```sh
   sdx link add agent https://203.0.113.5:8447 <token> <fingerprint>
   ```

   Команда открывает меню с конфигами, которые предлагает сервер. Перемещайтесь стрелками, отмечайте конфиги пробелом и подтвердите выбор клавишей Enter. Роутер импортирует выбранные конфиги как ожидающие изменения.

2. Примените изменения:

   ```sh
   sdx apply
   ```

   Команда сохраняет конфиги и запускает сервисы: поднимаются туннели, вместе с ними стартуют Router и DNS.

Дальше роутер забирает конфиги с сервера сам, а `sdx link agent ...` запускает `sdx` сервера с роутера.

## Проверьте статус

Запустите `sdx`:

```
Uplink:
  [*] Internet             118 ms
  [*] Overlay (anytls)     286 ms

[*] Router:
  Routing:      overlay
  Kill switch:  on
  Watchdog:     every 30s
  Rules:
    [*] ads                block    list
    [*] tv                 direct   1 client

[*] VPN:
  Configs:
    [ ] awg         362 ms
    [ ] wg          324 ms

[*] Proxy:
  Configs:
    [*] anytls      286 ms
    [ ] vless

[*] DNS:
  Upstream:   encrypted
  Resolver:   cloudflare
  Intercept:  on

Link:
  [*] admin        https://203.0.113.5:8447         2 vpn, 2 proxy, 4 min ago
```

Раздел **Uplink** показывает туннель, который несёт трафик. Работающий сервис отмечен `[*]`.

## Если что-то не работает

Если роутер не маршрутизирует трафик:

* `sdx logs` показывает логи сервисов.
* `sdx restart` перезапускает сервисы в правильном порядке.
